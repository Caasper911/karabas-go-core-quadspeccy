# План Quad Speccy

Цель: четыре независимых Pentagon 128 с индивидуальными ROM на Karabas Go, память в SDRAM.
Два режима показа: все четыре на одном экране и выбранная машина на весь экран.
Win+1..4 выбирает машину для клавиатуры, Win+`~ переключает полный экран / quad.
Сначала только Karabas Go, Mini / Mini G потом.

Как устроено, описано в [ARCHITECTURE.md](ARCHITECTURE.md).

## Открытые вопросы

- Передаёт ли прошивка MCU клавишу Win (бит 3 / 7 `KB_STATUS`) вместе с цифрами в ядро, или
  комбинации Win+цифра заняты прошивкой? Если заняты, нужны другие клавиши (например,
  ScrollLock / Pause + цифра).
- Какой чип SDRAM стоит на Karabas Go (объём, -6 / -7)? CL2 на 84 МГц взят из TS-Conf.
- Палитра (0xCA / 0xFF) и полярность синхроимпульсов: проверить на мониторе.
